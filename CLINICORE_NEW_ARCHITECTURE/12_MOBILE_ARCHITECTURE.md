# 12 — Doctor Mobile Application Specification

> **System:** CliniCore / ClinicFlow Master Architecture  

---

## 1. Technology Stack
- **Framework**: React Native + Expo + TypeScript
- **State Management**: Zustand / React Query
- **Push Notifications**: Expo Push Notification Service

## 2. Core Mobile Capabilities
- Real-time chamber queue monitoring.
- Biometric (FaceID / TouchID) sign-off for staff approval requests.
- Prescription camera attachment & patient vitals review.
